# Досье оперативников — русский перевод

Здесь лежат переводы личных досье оперативников (档案 / «档案资料», «基础档案»,
«客观履历», «临床诊断分析» и т.д.) на русский язык.

## Формат

Каждый оперативник — отдельный файл `<operator_id>.json`:

```json
{
 "operatorId": "char_002_amiya",
 "sourceLang": "en_US",
 "sections": [
  {
   "index": 0,
   "titleEn": "Basic Info",
   "titleRu": "Базовые данные",
   "textRu": "[Позывной] Амия\n[Пол] Женщина\n..."
  }
 ]
}
```

* `index` — порядковый номер секции в оригинале (совпадает с `index` в
  `.cache/dossiers/src/<operator_id>.json`), секции идут подряд.
* `titleEn` — оригинальный заголовок (нужен для сверки), `titleRu` — перевод.
* `textRu` — перевод текста секции. Переносы строк — `\n`, структурные теги
  `[Метка] Значение` сохраняются, метка переводится.

Эталон: `char_002_amiya.json` (собрано из `tools/build_dossier.py`).

## Как переводить

Источник: `.cache/dossiers/src/<operator_id>.json` (выгружается
`tools/dump_dossiers.py`): для каждой секции `titleEn` / `textEn` (английский) и
`titleZh` / `textZh` (китайский оригинал). **Переводим с английского, китайский
сверяем** — в спорах о деталях (имена, лор) прав китайский.

Рабочий формат — обычный текст `.cache/dossiers/ru/<operator_id>.txt`:

```
@@ 0 | Basic Info | Базовые данные
[Позывной] Амия
[Пол] Женщина

@@ 1 | Physical Exam | Физический осмотр
[Физическая сила] Норма
```

Затем `python3 tools/build_dossier.py <operator_id>` собирает JSON и проверяет:
состав секций, порядок индексов, пустые переводы и подозрительную длину.

## Правила перевода

1. Перевод читается как перевод игры: без «доктор»-избыточности, без машинных
   кальк, названия операций и персонажей не транслитерировать.
2. Имена собственные, локации и титулы — по глоссарию и по уже переведённым
   главам репозитория (`translation/ru_RU/`), а не «как получится».
3. Структуру не ломать: `[Метка] Значение` остаётся в квадратных скобках,
   метка переводится, значение переводится по смыслу; блоки `■■■` сохраняются
   как есть (в них «закрытые» данные).
4. Числа и единицы — как в оригинале (`142см` → `142 см`, `0.27u/L` → `0.27 ед/л`).
5. Знаки препинания — по-русски: тире `—` (одинарное), «ёлочки» для цитат,
   никаких `——`.
6. Ничего не выдумывать: если в оригинале `？？？` — так и оставить `？？？`.
7. Перевод должен быть полным: пропущенная секция или «сокращённый» перевод —
   ошибка (сборщик это поймает по длине).
